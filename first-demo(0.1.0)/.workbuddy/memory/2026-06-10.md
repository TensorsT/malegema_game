3. **调试信息泄露**：`board.gd` 的 score_label 里显示种子ID。

### 游戏性设计问题

1. **时间惩罚不可感知**：时间在后台跑，玩家没有倒计时UI，体验差。建议改为可视化时间奖励窗口。
2. **目标分数与实际可得分脱节**：目标分增长过快（纯数学公式），已有85% cap补丁是hack，建议改为基于牌组动态计算。
3. **"三张合成"规则隐藏**：合成只发生在商店，游戏板上没有感知，教程没有说明。

### 游戏架构理解

- 游戏流程：主菜单 → 游戏板 → 结算 → 奖励 → 商店 → 循环
- 核心：配对消除（两张相同牌），材质系统（bone→topaz→sapphire层级），龙/凤凰连击倍率
- 模块系统（dragons/phoenixes/gems/mutations/winds/jokers）已实现但视觉反馈不足
- SetupTiles 使用拒绝采样保证布局可解，正确实现
