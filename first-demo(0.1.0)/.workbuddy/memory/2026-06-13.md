## 开发者模式（跳过关卡按钮）

### 新增文件
- `scripts/dev_mode.gd`：`class_name DevMode`，仅含 `static var enabled: bool = false`
  - **后续改为 Autoload**：删除 `class_name`，改为 `extends Node` + `var enabled`，在 `project.godot` 注册为 Autoload 单例
  - **原因**：`class_name` 方式依赖 Godot 全局脚本类缓存，新文件未扫描时 Parse error；Autoload 保证先于所有脚本加载

### gameStar.tscn
- SettingsPopup VBoxContainer 中全屏模式下方新增 `DevModeCheck`（CheckBox，"开发者模式"）
- 信号 `toggled` → `_on_dev_mode_check_toggled`

- `_ready()` 初始化 `dev_mode_checkbox.button_pressed = DevMode.enabled`
- `_on_dev_mode_check_toggled(toggled_on)` → `DevMode.enabled = toggled_on`
- `_apply_whatajong_ui()` 加 `apply_display_font` + `tint_toggle` 给 dev_mode_checkbox

### board.gd
- 新增变量 `_skip_button: Button`
- `_setup_skip_button()`：创建红色"⏩ 跳过"按钮，锚定 GamePanel 右下角（PRESET_BOTTOM_RIGHT）
